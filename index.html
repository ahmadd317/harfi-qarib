يلزم إعداد Supabase

التطبيق جاهز، لكن لم تتم إضافة عنوان مشروع Supabase ومفتاح anon العام بعد.

  1. أنشئ مشروعًا في Supabase وشغّل ملف supabase-schema.sql.
  2. انسخ config.example.js إلى config.js وضع قيم window.HARFI_CONFIG العامة.
  3. انشر ملفات المشروع على Vercel كـ Static Site. التفاصيل في README.
window.HARFI_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_PUBLIC_ANON_KEY"
};
